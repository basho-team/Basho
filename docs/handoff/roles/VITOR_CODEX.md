# Vitor / Codex — núcleo do backend

Você é responsável pelo núcleo de dados, APIs, permissões, revisões e releases. Vitor é o responsável humano pelo backend e integração técnica.

## Entregas
- Inspecionar o repositório e identificar modelos/rotas existentes antes de criar novos.
- Ratificar CONTRATOS.md com as necessidades das demais frentes e publicar schemas, exemplos e OpenAPI.
- Implementar, quando autorizado, organização/projeto/pessoas/períodos, evidências versionadas, relatórios, revisões, pendências e referências financeiras/fiscais.
- Aprovações sobre versões exatas, transições autorizadas, snapshots e controle de concorrência.
- Persistência e contratos necessários aos workflows do Claude de Vitor.

## Limites
Não desenvolver sozinho os agentes de redação ou a interpretação fiscal; consumir os resultados estruturados dos módulos de Thiago. Não introduzir API financeira paralela. Modelos compartilhados e migrações são sua responsabilidade de integração, ouvindo quem os consome.

## Dependências e primeira entrega
Seu contrato destrava todos. Primeira entrega proposta: schemas e exemplos do fluxo mínimo, migrations essenciais e APIs para criar/consultar projeto, relatório e revisão. Fornecer exemplos válidos a Carlos antes de concluir todos os endpoints. Após isso, testar uma revisão real persistida.

## Aceite
Acesso indevido negado; relatório aprovado mantém sua versão; revisão concorrente de versão antiga gera conflito; snapshot preservado; exemplos da UI validam no schema. Ao concluir, revisão cruzada com Thiago e Carlos.
